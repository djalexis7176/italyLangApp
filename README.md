# Andiamo — Italian for travellers

A single-file web app. No build step, no dependencies, no server code. Works on a phone, in Chrome, Safari, Edge or Firefox, and on GitHub Pages.

## Put it online

1. Create a repository on GitHub (public), e.g. `andiamo`.
2. Upload `index.html` to the root of the repository.
3. Repository → **Settings** → **Pages** → under *Build and deployment*, set **Source: Deploy from a branch**, **Branch: main**, **Folder: / (root)** → Save.
4. Wait a minute, then open `https://YOUR-USERNAME.github.io/andiamo/`.

## On your phone

Open that URL, then **Share → Add to Home Screen** (iPhone) or **⋮ → Add to Home screen** (Android). It opens full screen like an app and remembers your progress on that device.

## Spoken Italian

The **Voice** button in the top bar cycles through the Italian voices your device has and steps the speed down to 0.7×. If nothing speaks, install an Italian voice: iPhone → Settings → Accessibility → Spoken Content → Voices → Italian. Android → Settings → System → Languages → Text-to-speech.

## What's inside

- 300 phrases across 18 travel situations, with pronunciation and audio
- 44 verbs fully conjugated in the present tense, with stem and ending colour-coded
- 100 nouns with their articles, 30 adjectives
- 52 question-and-answer pairs (they ask, you answer)
- 10 full role-play conversations
- 19 confusable word pairs with rules and practice
- 10 drill types and a 14-day plan

Progress, saved phrases and your streak are stored in the browser on that device only. **Plan → Clear all progress** resets everything.
